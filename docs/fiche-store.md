# Textes de la fiche Google Play

Textes prêts à copier dans la Play Console. Ils restent honnêtes, comme l'exige le programme Familles : pas de promesse exagérée ni de fausse urgence.

## Nom (30 caractères max)

```
Pépin Sprint
```

## Description courte (80 caractères max)

```
Cours, saute, glisse et habille Pépin ! Un jeu de course simple et joyeux.
```

## Description complète (4000 caractères max)

```
Pépin est un petit personnage qui adore courir ! Aide-le à aller le plus loin possible.

COMMENT JOUER
• Touche l'écran pour sauter, touche deux fois pour un double saut.
• Glisse le doigt vers le bas pour passer sous les obstacles.
• Une seule main suffit : touche n'importe où sur l'écran.

PLEIN DE CHOSES À DÉCOUVRIR
• 5 décors qui défilent pendant la course : crépuscule, forêt d'automne, plage de nuit, montagne enneigée et cosmos.
• 3 bonus : l'aimant à pièces, le bouclier et le turbo.
• Des combos jusqu'à ×5 quand tu enchaînes les obstacles.
• 3 nouvelles missions chaque jour.

HABILLE PÉPIN
• Des personnages, des chapeaux, des traînées et des effets de saut à débloquer avec les pièces gagnées en jouant.
• Tout est décoratif : rien ne rend Pépin plus fort.

PENSÉ POUR LES ENFANTS
• Aucun compte, aucune donnée personnelle demandée.
• Les publicités ne s'affichent que si tu choisis d'en regarder une, pour continuer une partie. Elles sont adaptées aux enfants.
• Option payante unique pour supprimer les pubs, et packs décoratifs facultatifs. Chaque achat demande l'accord d'un adulte.
• Fonctionne sans connexion internet.
```
